---
name: adhd-mode
description: 'Shows whether ADHD mode is on or off, and the options'
---

Use ONLY when the user types /adhd-mode. It never changes the mode.

Look back through this chat for the last /adhd-on or /adhd-off. Last was /adhd-on: ON. Last was /adhd-off, or none: OFF. Reply with exactly this, nothing else:

If ON:
```
ADHD mode: 🔵 ON

Options:
  /adhd-off  turn it off
```

If OFF:
```
ADHD mode: ⚪ OFF

Options:
  /adhd-on  turn it on
```
